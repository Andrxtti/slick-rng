# Slick RNG app

Installable, offline-capable build of Slick RNG, hosted free on GitHub Pages.

- `python3 build.py` rebuilds `index.html` and `sw.js` from `../app/slick-rng.html`.
- `icons/` holds the logo (`mark.svg`), app icons and iPhone launch images.
- Install on iPhone: open the site in Safari → Share → Add to Home Screen.
- Install on Android/desktop Chrome: open the site → Install app.
